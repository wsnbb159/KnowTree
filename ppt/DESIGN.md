# DESIGN.md — 知树 KnowTree 作品介绍

## 0. 风格路由结论

命中判断：这是**产品 / 技术介绍**场景（创新大赛作品评审），
不属于「学术科研 / 专业咨询 / 党政红色」三个垂直领域 → **走通用设计原则**（universal-only），
本文件即最终设计宪法。

**视觉调性**：技术可信 / 克制 / 数据驱动。
配色**延续网页版产品的品牌色**（深绿），让 PPT 与产品是同一个人格 —— 评委看完 PPT 点开链接时不会有割裂感。

## 1. 画布与母版

画布 **1280 × 720**。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px（上 padding 20） | 页面主标题 34px bold；左上角距 64px |
| **B · 内容区** | 120–660px | 540px 可用 | 一切正文、图表、配图、卡片；禁止挤占 A/C 区 |
| **C · 页脚条** | 660–720px | 60px（下 padding 20） | 左：`知树 KnowTree` 14px 灰；右：页码 `NN / 13` |
| 页面 padding | 上下 20px、左右 64px | — | A/B/C 均在 padding 之内排布 |

封面（01）、结束页（13）采用自定义版式，省略 C 区；其余内容页严格复用三区母版。

## 2. 颜色系统

### 2.1 色彩池

**4 个基础色**（严格执行，不新增）：

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 背景 | `#FBFAF7` | 全局画布底色（暖白，比纯白柔和） |
| 主色 | `#0F6E56` | 品牌深绿。标题栏、深色底块、巨型数字、因果链主线 |
| 辅色 | `#5DCAA5` | 浅绿。图表第二系列、次级标注、进度指示 |
| 文本 | `#1A1A1A` | 正文与标题文字 |

**3 个受控派生色**（同色系深浅，全篇不新增第六种）：

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 极浅绿 | `#E1F5EE` | 卡片底、区块底、浅色强调块 |
| 极深绿 | `#04342C` | 深色背景页（封面 / 结束页）底色 |
| 赭橙 | `#C2410C` | **唯一强调色**。只用于巨型数字与「断层」类关键标注 |

> 为什么给强调色单开一个色系：知树的核心叙事是「断层 → 源头」，
> 需要一个与主色对比的颜色把「出问题的地方」标出来。橙色在深绿旁对比最清晰，
> 且不引入第二种「主色感」。

### 2.2 色彩面积分配（逐页）

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色 | ≤ 55% | 背景块、标题栏底、图示主线 |
| 辅色 | ≤ 25% | 卡片底、图表第二系列、分隔 |
| 强调色 | ≤ 10% | 仅焦点元素（巨型数字、断层标注） |
| 中性 | 剩余 | 文本、页脚、边框 |

**色彩节奏**：
- Hero 页（01 / 04 / 13）：强调色占比可到 15–20%
- Supporting 页：强调色 ≤ 5%，辅色 ≤ 20%
- **刻意制造差异**：第 1、13 页用**深底反白**（极深绿铺底），第 4、7 页用**浅底 + 巨型数字**，
  其余为浅底信息页 —— 全篇至少有 3 组明显不同的色彩比例。

### 2.3 渐变与半透明

- 封面 / 结束页：`linear-gradient(160deg, #04342C 0%, #0F6E56 100%)`
- 卡片：`boxShadow: '0 4px 20px rgba(15,110,86,0.08)'`
- 深色底上的文字：`rgba(255,255,255,0.92)`，次要信息 `rgba(255,255,255,0.62)`
- 浅色底的次级块：`rgba(15,110,86,0.06)`
- 禁止在正文页使用高饱和大面积渐变。

## 3. 字体系统

| 层级 | 字体 | 字号 | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 思源黑体 | 76px | bold | 1.2 | 仅第 1 页 |
| 章节大字 | 思源黑体 | 60px | bold | 1.15 | 结束页、金句页 |
| **巨型数据** | Inter | **104px** | **bold** | 1.0 | 第 4、7 页锚点数字 |
| 页面主标题 | 思源黑体 | 34px | bold | 1.3 | 每页 A 区固定 |
| 卡片小标题 | 思源黑体 | 26px | 600 | 1.4 | 卡片头 |
| 正文 | 思源黑体 | 22px | regular | 1.55 | 段落 |
| 引文 / 注释 | 思源黑体 | 18px | regular | 1.5 | 「」、图示标注 |
| 页脚 / 页码 | Inter | 14px | regular | 1.4 | C 区 |

**字体策略**：
- 正文与标题统一用**思源黑体**（商务现代、可信，中文字形完整）；
- **巨型数字用 Inter**（西文数字更挺拔、字距更匀），与正文形成刻意的字重与字体跳跃 ——
  这是每页「视觉锚点」的主要手段；
- 代码 / 节点 id 用 `JetBrains Mono`（等宽，只在技术页出现，如 `ds.stack.callstack`）；
- 数字统一用 Inter，避免中文数字与西文数字混排。

## 4. 信息密度

| 页面类型 | 字数下限 | 图数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- |
| 封面 | 20 | 1 | ≥ 35% |
| 内容页 · 单主题 | 180 | 1 | ≥ 30% |
| 数据页 | 80 | 1 主图 | ≥ 50% |
| 结束页 | 20 | 0–1 | — |

**留白上限**：常规内容页 ≤ 35%；Hero 页可到 45%（留白必须围绕焦点元素）。
**容器填充率**：卡片内容垂直占用 ≥ 85%；尾部元素用 `marginTop:'auto'` 钉底。
**横向兄弟卡对齐**：同行卡片的标题块 / 正文块 / 尾部条三段 y 轴等高（差 ≤ 16px）。

## 5. 配图系统

**本项目不使用 AI 生图**，理由：这是产品介绍，最有说服力的是**产品的真实界面**，
而不是风格化的配图。用真实截图 + SVG 图示，既更可信，也避免风格不统一。

| 等级 | 用途 | 最小尺寸 | 来源 |
| :--- | :--- | :--- | :--- |
| **L1 · 主视觉** | 承担页面主要叙事 | B 区 ≥ 40% | 产品真实截图 / SVG 结构图 |
| **L2 · 支撑图** | 强化某个段落 | ≥ 280×180 | SVG 小图示 |
| **L3 · 母版徽标** | 全篇统一的角标 | ≤ 64×64 | 「知树」文字标（C 区左侧，全篇位置一致） |

**素材清单**（均由真实产品截取，存放于 `resources/images/`）：

| 文件名 | 内容 | 用于页 |
| :--- | :--- | :--- |
| `shot_capture.png` | 拍题诊断首页（含内置样例卡） | 02 |
| `shot_diagnosis.png` | 诊断报告的卡点归因区（含因果链） | 04 |

**SVG 允许范围**：流程链路图、因果链关系图、巨型数字、进度指示、L3 文字标、封面几何图形。

**风格约束**：截图统一从线上版本按 1280 宽截取，保证清晰度一致；

## 7. 实现备注（生成后发现并记录的调整）

**生成方式**：本机 SlideP 渲染服务（`editor_sdk`，8 月构建）与 CLI（`0.4.4-alpha`）版本不匹配，
`/localapi/keyframe` 端点缺失，无法通过 SlideP 生成。
改用 **python-pptx** 直接编写生成器 `build_deck.py`（13 页全部程序化生成），
完全可控、无外部服务依赖。

**与本文档的偏差**：

| 项 | 原设计 | 实际实现 | 原因 |
| :--- | :--- | :--- | :--- |
| P7 主视觉 | `shot_profile.png` | 巨型数字「13 → 4」+ 源头清单 | 该页核心是一组数字的转化关系，清单（8 个被拖垮的知识点）比截图更有说服力；`shot_profile.png` 未使用 |
| 渐变色 | 封面/结束页用 `linear-gradient` | 改为纯深绿 `#04342C` / `#0F6E56` | python-pptx 对渐变支持有限，纯色更稳妥且观感一致 |
| 配图数量 | 6 张截图 | 实际使用 5 张（P2/P4/P6/P8/P9） | 同上 |

**自检结果**（程序化）：
- 13 页共 322 个形状，**越界元素 0 个**
- 文本内容逐页核验通过；5 张截图均正确嵌入
- 未做视觉渲染验证（本机无 LibreOffice；PowerPoint 已安装但需用户授权方可调用）
